观数 · 宏观预测平台 v3 —— 上传与部署步骤
=========================================
网址不变：https://macro-nowcast.onrender.com

【第一步】把这个文件夹里的文件传到 GitHub
1. 浏览器打开 https://github.com/chuanbosun76-blip/macro-nowcast
2. 点仓库文件列表上方的 "Add file" → "Upload files"
3. 打开桌面上的 macro-nowcast-v3 文件夹，全选里面的所有文件
   （Mac：在文件夹里按 Command + A 全选），直接拖进浏览器那块虚线区域
   注意：是拖“文件夹里的文件”，不是拖文件夹本身
4. 页面下方 "Commit changes" 的输入框里随便写一句（例如：v3 依据引擎+月季年频率+报告导出）
5. 点绿色按钮 "Commit changes"
6. 页面会问是否覆盖同名文件 —— 选覆盖（Commit 即覆盖）

【第二步】让 Render 重新部署
1. 浏览器打开 https://dashboard.render.com
2. 点进 macro-nowcast 这个服务
3. 右上角 "Manual Deploy" → 选 "Deploy latest commit"
4. 等状态从 Building → Live（约 3–6 分钟）
5. 打开 https://macro-nowcast.onrender.com 强制刷新一次
   （Mac：Command + Shift + R）

【第三步】确认新版生效
打开网站后左侧菜单应该有 12 项，其中新增了：
  搜索、报告生成
右上角应该有金色的「一键更新」按钮。
数据库页应该有「月度 / 季度 / 年度」三个页签。

【这次更新了什么】
1. 依据引擎：每个指标自动生成「结论先行 + 不少于 5 条量化支撑」
   （基准与惯性 / 时序模型与季节性 / 因子贡献分解 / 领先信号扫描 /
     基数与翘尾 / 历史相似期 / 桥方程追踪 / 组合与不确定性 / 跨频率含义）
   每条都带统计量与方法出处，再给风险情景与对股债的隐含影响。
2. 月度 / 季度 / 年度三套频率：GDP 可以选月（桥方程追踪）、季、年；
   其他指标可以看当季/当年的已实现部分 + 模型外推 + 已实现占比。
3. 第四种模型「桥方程」（亚特兰大联储 GDPNow 思路）+ 组合预测（Bates–Granger）。
4. 内嵌 7 套权威机构方法论（GDPNow / 纽约联储 DFM / 克利夫兰联储 /
   MIDAS 组合 / 信达高频 / 中金论证结构 / IMF 年度口径），含公式、步骤、
   公开精度与本平台的具体应用方式；教程与搜索里都能查到。
5. 指标从 47 项扩到 80 项（中国 56 + 美国 24），全部按一级/二级分类归好；
   市场库扩到 21 个标的（A股宽基、恒生、美股三大、日经、美元指数、
   USDCNH、黄金、原油 + 中美 2Y/10Y/30Y）。
6. 新增「搜索」页：指标、市场、机构方法论、计算方法、预测因子一起搜。
7. 新增「报告生成」页：Word / PPT / Excel / Markdown 一键导出；
   AI 可以按你写的 prompt、基于平台数据库写研报再导出。
8. 「一键更新」按钮：重抓数据 → 重算全部模型 → 刷新市场库，
   看板 / 预测中心 / 数据库 / 回测 / 档案自动同步。
9. 页面整体重做（配色、层级、卡片、深色看板）。

【可选】设置里填 API Key 才能用 AI 研判
Render → Environment → 添加 DEEPSEEK_API_KEY（或 ANTHROPIC_API_KEY）
不填也能用：五种方法里的前四种（统计模型）不需要任何 Key。
