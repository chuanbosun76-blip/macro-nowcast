一、平台是什么

这是一个宏观指标实时预测（nowcasting）+ 资产传导平台。它解决的问题是：官方数据有 1–6 周的发布时滞，在数据公布前，市场已经在对它定价。平台把公布前可得的一切信息——指标自身的历史规律、同期已公布的关联指标、当月券商研报的集体判断——压缩成一个带区间的数值预测，并给出这个预测如果兑现，对股债的历史含义。

覆盖范围：中国 22 项、美国 25 项月度/季度宏观指标，历史自 2005–2008 年起（多数 200+ 期）；市场数据库含中美港 7 个主要股指与中美 2Y/10Y 国债收益率，2005 年起月度。数据每小时自动轮询更新，有新数据可自动触发预测。

与 Wind / iFinD 的关系：那些终端是数据的权威来源与查询工具，本平台是数据之上的预测与归因层。终端告诉你"8 月出口同比是多少"，本平台回答"9 月出口大概率是多少、凭什么这么判断、如果对了 A 股出口链会怎样"。两者互补，不替代。

进入 总览 → 选国家 → 找到指标卡片。卡片顶部写明"本次预测 → 2026年9月数据 · 预计 10/15 公布"，这就是预测对象；下面四个方框是四种方法各自的答案，红框是按回测择优推荐的那个。点开卡片里的 「预测依据 · 为什么这样预测」，能看到每种方法的完整推导（样本期、模型阶数、检验 p 值、回测表现、置信区间）。点 「详情」 打开抽屉，里面有历史曲线对照、AI 研判全文、引用研报直达链接、以及传导分析表。

场景 B：我想让 AI 现在就跑一次预测

进入 预测中心 → 选模型（DeepSeek / Claude）→ 选输入方式（推荐"研报标题 + 数据研判"）→ 勾选指标 → 点"仅对勾选指标运行 AI 研判"。或直接点 「更新最新数据并预测全部待测指标」，会先拉取最新官方数据、增量重算统计模型，再对所有待公布指标跑一遍 AI。每个指标约 15–60 秒。

三、四种预测方法与数学公式

对每个待测指标，平台同时跑四种方法，并按历史回测表现推荐其一。四种方法的信息集是递进的：从只用自身上期，到用自身全部历史，到用全体关联指标，再到用文本信息。

方法一：沿用上期（Random Walk 基准）

ŷt = yt−1

看似简单，但它是所有预测研究的基准线（benchmark）。金融计量的一个经典结论是：对高持续性序列，随机游走极难被战胜。若某方法跑不赢它，说明该方法没有提取到额外信息。平台的决策规则中，当 corr(yt, yt−1) ≥ 0.8（惯性极强）时直接采用本方法，除非多因子模型能显著超越（提升 ≥ 0.05）。

方法二：SARIMAX（季节性 + 外生变量的时间序列模型）

完整设定为回归项 + SARIMA 误差结构：

yt = β′xt + ηt，　φ(L)(1−L)d(1−L12)D ηt = θ(L) εt，　εt ~ WN(0, σ²)

其中 φ(L) = 1 − φ1L − … − φpLp 为自回归多项式，θ(L) = 1 + θ1L + … + θqLq 为移动平均多项式，L 为滞后算子（L yt = yt−1）。

外生变量 xt（春节效应）：中国 1–2 月数据受农历春节错位严重干扰。平台用 2008–2035 年农历新年日期表，构造当月春节假期天数占比：

xt = （落在月 t 内的春节假期天数）/（月 t 的天数）

对 CPI 环比、社零、贸易差额等季节敏感指标启用（卡片上标注"春节"标签）。

差分阶数 d 的确定：先做 ADF（Augmented Dickey–Fuller）单位根检验，回归式为

Δyt = α + ρ yt−1 + Σi=1..k γi Δyt−i + εt，　检验 H0: ρ = 0（存在单位根）

t 统计量按 MacKinnon 临界值表转换为 p 值。p < 0.05 拒绝原假设（序列平稳）→ d = 0；否则 d = 1。部分指标（如 CPI 环比）按经济含义强制 d = 0。

阶数 (p, q) 的选择：在 p ≤ 3、q ≤ 2 的网格上最小化 AIC：

AIC = 2k − 2 ln L̂ = n ln(σ̂²) + 2k + const

k 为参数个数，L̂ 为极大似然值。平台每年 1 月重选一次阶数，模拟真实场景下分析师定期重估模型的做法。

参数估计：条件平方和（CSS）法，用 scipy 的 Levenberg–Marquardt 最小二乘最小化 Σ εt²。AR 部分的平稳性通过 PACF 变换（Barndorff-Nielsen–Schou 变换）参数化，保证特征根始终落在单位圆内。

残差检验：Ljung–Box Q 统计量检验残差是否为白噪声：

Q(m) = n(n+2) Σk=1..m ρ̂k² / (n−k) ~ χ²(m−p−q)

p 值大（如 > 0.05）说明残差无显著自相关，模型已充分提取线性信息。详情抽屉里的"ADF p / LB p"即此二项。

预测区间：取最近 36 期样本外残差的标准差 σ̂，按正态近似给出 80% 区间 ŷ ± 1.28 σ̂。这是经验区间而非理论区间，因为它直接来自模型在真实回测中的表现，比参数化区间更诚实。

方法三：多因子岭回归（横截面信息）

SARIMAX 只用指标自身历史。但现实中，出口的线索藏在 PMI 新订单和进口里，信贷的线索藏在 M1 和社零里。方法三把同一国家全部月度指标纳入特征集：

yt = α + Σj βj zj,t + εt，　zj,t = (xj,t − μj) / σj

特征 xj,t 包含：自身滞后 1 期、2 期、12 期（捕捉惯性与年度季节性）；以及每个关联指标——领先指标（PMI、ISM、消费者信心、政策利率，当月即公布）取当期值，其余指标取滞后 1 期（因为预测 t 月时 t 月数据尚未公布，只有 t−1 月可得）。这一设定严格保证了信息可得性，不存在前视偏差。

为什么用岭回归而非 OLS：特征数可达 20+ 而有效样本仅 150–250，且宏观指标间高度共线（M1 与 M2、社零同比与累计同比）。OLS 在共线下方差爆炸。岭回归加 L2 惩罚：

β̂ridge = argminβ { ‖y − Zβ‖² + λ‖β‖² } = (Z′Z + λI)−1 Z′y

λ = 1（特征已标准化）。这在偏差-方差权衡中用少量偏差换取大幅方差下降，即 James–Stein 收缩的思想。

特征筛选防泄漏：只用回测起点之前的样本（约前 36–72 期）计算 |corr(xj, y)| 排序，取前 8 个特征，并强制保留自身滞后 1 期。若用全样本筛选特征，回测结果会被严重高估——这是量化研究中最常见的作弊形式之一。

扩展窗口重估：预测第 t 期时，模型只用 1…t−1 期数据拟合，每 3 个月（及每年 1 月）重新估计一次系数。

预测依据面板里会列出被选中的特征与标准化系数（绝对值前 5），可直接读作"该指标当前主要由哪几个变量驱动"。

方法四：AI 研判（文本 + 数据 + 模型）

前三种方法都无法读取"文字"。但券商研报里包含高频跟踪数据（港口吞吐、开工率、票据利率、乘用车批发）、政策解读与拐点判断——这些是数值序列里没有的信息。方法四把当月研报交给大模型：

  1. 召回：从东方财富研报中心抓取目标月内发布的全部宏观研究 + 策略报告（通常每月 200–400 篇），按指标关键词（如出口指标用"出口/外贸/关税/海关/集装箱/港口/订单"）+ 用户自定义规则筛选、去重，得到相关标题列表（含机构、日期、直达链接）。
  2. 严格时点截断：只取目标月最后一天及之前发布的研报。回测某个历史月时，系统自动把 cutoff 设为该月末，绝不会读到之后的文章。
  3. 组装 Prompt：目标指标近 24 期历史、同国关联指标最新值、沿用上期值、SARIMAX 预测值及其回测相关性、多因子回归预测值及其特征、该指标的理论驱动因素、研报标题列表、用户附加要求。
  4. 结构化输出：强制模型返回 JSON，包含 forecast（数值）、low/high（区间）、direction、confidence、summary、drivers（驱动因素）、mechanism（传导机制）、evidence（证据，须指向具体研报）、risks（风险）、vs_models（与统计模型的差异及原因）。

四种输入变体可在"输入"下拉中切换：研报标题（推荐，信噪比最高）、研报正文片段（信息更全但噪声大、成本高）、标题 + 自回归参考（强调统计锚定）、仅数据（对照组，用于分离"研报到底有没有用"）。

方法择优的决策规则

推荐哪一种不是拍脑袋，而是按固定规则从回测表现推出：

条件推荐含义
corrpersist ≥ 0.8 且多因子未显著超越沿用上期惯性主导，任何模型都是噪声
AI 回测样本 ≥ 12 期同窗口 corr 最高者有实证证据时以证据为准
corrmf ≥ 0.5 且超越其余方法多因子回归横截面信息有效
corrar ≥ 0.5 且超越沿用上期 0.05+SARIMAX时序结构有效
corrpersist ≥ 0.7沿用上期统计模型无显著提升
以上皆不满足AI 研判惯性弱、外生冲击主导，需读文本

四、回测方法与三重检验

扩展窗口回测（Expanding Window）

预测第 t 期时只用 1…t−1 期的信息重新拟合模型，逐月推进，绝不使用未来数据。这与"用全样本拟合一次再看拟合优度"有本质区别——后者是样本内拟合，几乎必然好看，但没有任何预测意义。

四个评价指标

corr = Cov(y, ŷ) / (σy σŷ)　　RMSE = √( Σ(ŷt − yt)² / n )　　MAE = Σ|ŷt − yt| / n　　方向命中率 = (1/n) Σ 1{ sign(ŷt − yt−1) = sign(yt − yt−1) }

平台主排序用 corr（与中金研究口径一致，便于横向比较），但请同时看 RMSE：corr 高而 RMSE 大意味着"方向对、幅度错"。对交易而言方向命中率往往更重要。

相关系数怎么读：0.9+ 通常来自高惯性指标（如 M2、美国 CPI 同比），此时"预测"的贡献其实很小；0.5–0.7 对波动型指标（出口、信贷、非农）已属相当好；低于 0.3 说明该指标基本不可预测，应当承认而非强行给数。

泄漏检验（Leakage Test）

大模型的训练数据可能已包含历史宏观数据。若模型"记得"2019 年 8 月出口是多少，回测就毫无意义。检验方法：以模型知识截止日为界（默认 2025-01）把回测样本切成两段，比较：

Δ = corr截止前 − corr截止后

若 Δ 很大（如 0.9 vs 0.3），说明历史段的优异表现来自记忆而非推理，AI 的真实能力应以截止后那一段为准。平台同时给出同窗口的沿用上期基准，排除"某段时期本身就好预测"的干扰。

可复现性

每一次预测都写入预测档案：目标月、信息截止日、完整 Prompt、模型原始输出、思考过程、引用研报清单、耗时与 token 数。任何一个数字都可以点进去看到它是怎么来的，也可导出 CSV 做二次分析。

五、传导分析：预测出来能干什么

预测本身不是终点。分析师真正要回答的是"这个数据出来，我该买什么"。传导分析回答三个问题：理论上该怎样、历史上实际怎样、这次预测隐含多大冲击。

惊喜（Surprise）的构造

市场对预期差定价，不对水平定价。缺乏 Bloomberg 一致预期数据时，标准学术做法是用时间序列模型的事前预测作为预期代理（Andersen–Bollerslev–Diebold–Vega 2003 的方法）：

st = yt − ŷt|t−1　（ŷ 为 SARIMAX 扩展窗口事前预测，缺失时退化为上期值）

并按其标准差标准化：zt = st / σs。

事件回归

rt+k = α + β · st + εt

其中 r 为数据公布当月的市场反应：股指取月度对数收益率 r = 100·ln(Pt/Pt−1)（单位 %），国债收益率取月度变动（单位 bp）。k 为发布时滞（大多数月度指标次月公布，k = 1；PMI 当月公布，k = 0；贸易帐等隔月公布，k = 2）。

报表中每一列的含义：

列含义与读法
理论方向经济学框架下"正向惊喜"应导致的方向（见下）。○ 表示方向取决于所处周期。
β（每 1σ 惊喜）惊喜每超预期 1 个标准差，该资产当月的平均反应（股指 %，债券 bp）。这是标准化 β，可跨资产比较。
t 值β / SE(β)。|t| ≥ 1.96 标记 *，即 5% 水平显著。样本 n≥24 才计算。
R²该惊喜解释了市场月度波动的百分之几。普遍在 0–5%，这是正常的——若某个宏观数据能解释 30% 的月度收益，那才该怀疑数据有误。
方向一致率惊喜与市场反应同号的比例。50% 为随机，持续 >55% 才有意义。
正/负惊喜均值反应非参数视角：把样本按惊喜正负分组，看两组的平均市场反应。可检查关系是否对称（常见的是"利空反应大于利多"）。
两个月累计 β把公布当月与次月收益相加再回归，检验冲击是持续还是反转。若两月 β 显著小于单月 β，说明市场当月反应过度、次月修正。
近 5 年 β仅用最近 60 期样本估计。与全样本 β 差异大 = 关系不稳定，应以近期为准。
理论 vs 实证✓ 一致 / ✗ 相反。出现 ✗ 且 t 值显著时值得深究——往往意味着该变量在当前周期被市场赋予了相反解读（"坏消息=好消息"）。
本次隐含= β × z本次，即"若本次预测兑现，按历史关系该资产当月的隐含反应"。这是把宏观预测翻译成资产观点的直接桥梁。

五条传导渠道（理论方向的来源）

① 盈利渠道（分子）：增长类数据 → 企业营收与盈利预期 → 股指。数据强则股指偏多。

② 贴现率渠道（分母）：通胀与就业数据 → 央行政策路径 → 无风险利率 → 估值。通胀超预期则长久期资产（成长股、长债）受损最重。这解释了为什么美国 CPI 对纳指的负向 β 通常大于对道指。

③ 流动性渠道：中国信贷/社融 → 实体融资与资金面。信贷脉冲扩张领先经济企稳 3–6 个月，是 A 股顺周期板块最重要的择时变量之一。

④ 汇率与跨境渠道：美国数据强 → 美元与美债收益率上行 → 新兴市场资金外流、人民币承压 → A/H 股受压。这是"美国数据影响中国股市"的主通道，也是本平台对中美两国指标都给出跨市场传导的原因。

⑤ 状态依赖：同一数据在不同周期符号相反。典型如美国非农：扩张期"弱非农 = 降息预期 = 股市涨"，衰退担忧期"弱非农 = 衰退确认 = 股市跌"。因此平台同时给出全样本 β 与近 5 年 β，两者背离时以近期为准，并在 AI 研判中要求模型说明当前处于哪种状态。

纪律：R² 低意味着这些关系只能用于方向判断与相对强弱排序（例如"这次 CPI 超预期，对创业板的压力大于沪深300"），不能作为单一交易信号。真正的数据日交易需要分钟级数据与期权隐含波动率，不在本平台范围内。

六、分析师工作流建议

月度循环

  1. 月初（1–5 日）：看 实时看板 的发布日历，确认本月关键数据日程；对 PMI/ISM 等当月公布的景气指标先跑一轮预测。
  2. 数据周前 2–3 天：进入 预测中心，点"更新最新数据并预测全部待测指标"。此时当月研报已积累到一定数量，AI 研判的信息量最充分。
  3. 写观点：打开重点指标的 详情，把"预测依据"四段直接作为逻辑框架——沿用上期给基准、SARIMAX 给季节性与惯性、多因子给横截面驱动、AI 给政策与高频线索；传导分析表给资产含义。研报引用链接可直接放进底稿。
  4. 数据公布后：回到 预测档案 对照预测值与真实值，记录偏差原因。系统会自动把新数据并入序列、重算模型，下个月的预测随之改进。
  5. 季度复盘：在 回测 页把区间设为最近一年，检查各方法的相关系数是否发生结构性变化；必要时在设置里调整预测要求或研报召回规则。

把预测转化为投资观点的三个层次

宏观层：多个指标的预测合在一起就是对当前经济动能的判断。例如同时预测到出口走弱、信贷不及预期、PPI 继续负增长，指向"总需求不足 + 通缩压力"，对应的政策预期是降准降息与财政加码。

债市：增长与通胀预测直接对应收益率方向。预测 CPI 低于预期 + 信贷收缩 → 降息空间打开 → 做多利率债；同时看传导表中该指标对中债 10Y 的 β 与近期稳定性。曲线形态上，通胀惊喜主要冲击短端（2Y，政策预期），增长惊喜主要冲击长端（10Y，期限溢价与名义增速）。

股市：分子看增长（工业、社零、出口），分母看通胀与利率。传导表给出对沪深300 / 创业板 / 恒生 / 标普 / 纳指的差异化 β——创业板与纳指久期长，对利率与通胀惊喜更敏感；沪深300 与道指偏价值，对增长惊喜更敏感。板块层面可按指标映射：出口 → 电子/机械/纺服；信贷 → 银行/建材/地产链；PPI → 煤炭/有色/化工；社零 → 食饮/家电/汽车。

什么时候不要相信这个平台

① 该指标的最优方法回测相关系数低于 0.3（平台会推荐 AI，但本质上是承认统计不可预测）；② 出现结构性断裂（口径调整、疫情、政策框架突变），历史关系失效；③ AI 研判的置信度标为"低"或其区间宽度超过指标自身波动率；④ 传导表中理论与实证符号相反且 t 值不显著——此时两边都不足以支撑结论。

八、局限与使用纪律

① 预测精度存在天花板。 宏观指标的可预测性由其自身性质决定。M2、美国 CPI 同比等高惯性指标相关系数可达 0.95+，但这主要来自惯性；出口、信贷、非农等真正有信息量的指标，0.5–0.7 已是优秀水平。任何声称能把非农预测到 0.9 相关性的方法，都应当先怀疑是否存在数据泄漏。

② AI 回测尚需你亲自跑。 平台内置的统计模型回测是实时计算的，但 AI 那几列默认为空——因为每一个数据点都意味着一次真实的模型调用与成本。在你跑过 AI 历史回测之前，"AI 研判"的推荐仅基于决策规则而非该指标的实证表现，请勿把它当作已验证的结论。

③ 传导关系不稳定。 样本期跨越 2010 年以来的去杠杆、疫情、通胀冲击等多个截然不同的政策环境。全样本 β 是这些状态的加权平均，未必代表当下。务必对照"近 5 年 β"与"两个月累计 β"判断稳定性。

④ 月度频率会稀释事件效应。 真实的数据日冲击集中在公布后数小时内，用月度收益衡量会被当月其他事件淹没。本平台的传导分析给出的是月度层面的统计关系，方向参考价值大于幅度参考价值。

⑤ 这是研究工具，不是投资建议。 所有预测均为模型与模型输出，不构成任何证券的买卖建议。使用者应独立判断并自行承担风险。
